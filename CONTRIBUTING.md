# Contributing to PT/OS One

PT/OS One is meant to be useful to people who know little or nothing about AI. If something is confusing, doesn't work, or could be easier, that feedback matters. **You don't need to be a programmer to contribute.**

## Report a problem or suggest an improvement

[Open a GitHub issue](https://github.com/cooperman411/plain-text-os-one/issues) and explain what happened in ordinary language.

When relevant, tell us:

- **Which AI you used:** For example, ChatGPT, Claude, Gemini, Duck.ai, or Lumo. Mention the plan or app only if it affects the result.
- **How you started:** Did you use the one-line GitHub prompt, paste `AGENT.md`, or open an existing PT/OS One document?
- **What you tried:** What did you ask the AI to do?
- **What happened:** What worked, what failed, or what was confusing?
- **What you expected:** What would have made the experience better?

You don't need to diagnose the problem or suggest a technical solution.

## What helps most

- **First-time setup:** Report unclear steps, inaccessible links, or instructions that assume technical knowledge.
- **Document quality:** Point out missing information, unnecessary complexity, or problems updating and saving your single document.
- **Compatibility corrections:** Tell us what a particular AI can or cannot actually do. Include the date, configuration, and a vendor source or reproducible test when possible.
- **Practical workflows:** Share examples of useful things PT/OS One can help with in basic chat, and what requires authorized tools.
- **Clearer writing and accessibility:** Suggest simpler language, better examples, or translations. Open an issue before starting a translation so work isn't duplicated.

PT/OS One is the **single-document** project. The original [PT/OS Workspace](https://github.com/cooperman411/plain-text-os) is a separate, multi-file approach. Please report issues in the repository for the version you're using.

## Propose an edit

If you're comfortable using GitHub, you can submit a pull request. Keep changes focused and explain why they're useful.

For changes to AI capability claims, provide a current source or repeatable test and identify anything you haven't verified. Keep related wording consistent across the [README](README.md), [setup guide](AGENT.md), and [compatibility guide](CAPABILITY-MATRIX.md).

**Simplicity comes first.** Please don't add required apps, subscriptions, integrations, complicated file structures, or technical steps just because they're possible. A basic chat assistant should remain enough to use PT/OS One.

## Privacy and conduct

GitHub issues and pull requests are public. **Do not post your personal PT/OS One document**, private conversations, emails, account credentials, API keys, access tokens, or other sensitive information. Remove private details from screenshots and examples before sharing them.

Be direct and respectful. Useful criticism is welcome, regardless of technical experience.

There is no formal review schedule. Some suggestions may need more testing before they can be incorporated.
